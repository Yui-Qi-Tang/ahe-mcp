# E4B 自主修補：有無 AHE、成功後接續與原樣重播

在同一個 scikit-learn 25570 問題上，E4B-only 在第 **18 輪**首次全過，E4B＋AHE 在第 **34 輪**首次全過。兩組成功後加入自身歷史再跑一輪，都未再次全過；還原各自成功輪的完整輸入，各重播一次，則都重現原回答與全過結果。這批實驗沒有顯示 AHE 的修補效率或固定輸入重現性優勢。

本文整理 2026-10-11 至 2026-10-12 已完成的 **AHE MCP Product** 實驗；沒有新增模型呼叫、測試或事後重評。可查詢的 [逐輪成績與成本](evaluation/e4b-autonomous-repair-20261012.json) 保留失敗、未送測、收集失敗及使用者中止。其他歷史實驗仍各自保留，不合併成新的成功率。

## 首次成功之前

「全過」要求同一補丁實際通過 **3 個目標測試＋184 個既有測試**，並非整個 scikit-learn 測試庫。修補輪數、模型呼叫及工具行動分開計算。

| 流程 | 首次全過 | 模型呼叫 | 模型工具行動 | 實跑完整 187 項的補丁 | 輸入／生成 tokens |
| --- | --- | ---: | ---: | ---: | ---: |
| 固定取證 E4B＋AHE | 未觀察到；80 輪完成分類，第 81 輪評測被使用者中止 | 81 | 0 | 47，均未全過 | 1,988,620／343,929 |
| 自主 E4B＋AHE | 第 34 輪 | 194 | 160 | 20；19 未全過、1 全過 | 2,562,362／222,529 |
| 自主 E4B-only | 第 18 輪 | 48 | 30 | 7；6 未全過、1 全過 | 385,034／97,845 |

固定取證由控制器操作真實 MCP，模型每輪回答一次，不能自行查歷史。它直接收到原始資料、合法補件、最近失敗與最近一次實測失敗（去重最多兩份），以及歷史索引。自主流程則由模型選擇查詢。兩者資訊交付及互動預算不同，不是單一變因比較。

固定流程另有 1 份補丁造成收集失敗、32 輪未送測，第 81 輪没有完整成績；中止不算模型失敗。47 次完整評測中，32 次為 3/3＋168/184、7 次為 0/3＋184/184、8 次為 0/3＋168/184。

E4B-only 共提交 8 份可構造補丁，其中第 9 輪引入語法錯誤，實跑 0 項；不把它寫成 187 項全失敗。tokens 累計每次模型呼叫的供應端計數，包含重複輸入脈絡及生成的 thinking 文字。牆鐘約為固定流程 7 小時 23 分、自主 AHE 3 小時 38 分、only 63 分鐘；含資料準備與評測，且不同執行時段／硬體競爭不能作等成本基準。

## 兩組自主流程的共同條件與差異

共同條件是同一原始 issue、相同 15 份原文、固定模型權重與生成設定、相同測試選取。沒有同伴、跨組失敗分享或人工解題提示。這是推論實驗，沒有訓練模型。

每輪重開模型 context，對原始程式重新交完整補丁。只有本組歷史、合法補件與可用筆記延續。每輪最多 16 個工具行動，再至多 1 次 final；沒有總修補輪數上限，首次全過即停止。完整歷史正文可查，初始輸入只自動列目錄；目錄可見不等於正文已送達。

| 條件 | E4B-only | E4B＋AHE |
| --- | --- | --- |
| 來源讀取 | 本組檔案分頁 | 真實 MCP 讀回後分頁 |
| 資料儲存 | 無 AHE／PG | 每輪全新隔離 PG，只重播自身資料 |
| 工具 | 讀來源、補件、讀／寫／列筆記，共 5 種 | 6 個 Query 工具，加讀來源／續讀／補件，共 9 種 |
| 筆記 | 允許，但實際沒有使用 | 無筆記工具 |
| 已存在來源的補件回覆 | 回傳實際可讀 ID | 原凍結版本曾回傳不可讀補件 ID |
| 第 1 輪初始 prompt 字元 | 13,950 | 24,315 |
| 成功輪初始 prompt 字元 | 17,846 | 33,214 |
| action schema JSON 字元 | 2,735 | 11,588 |

字元不是 token。工具、提示長度、筆記能力、補件 ID 行為及自身歷史同時不同；18 對 34 輪只能描述這兩條流程，不能隔離 AHE 的因果效果。兩組在首次成功前都沒有新增原始碼補件。

AHE 的資料準備使用 **TEST APPROVAL STUBS**，只模擬公開測試資料的審閱決定；來源寫入、接納、Query 及四個角色的實際連線均執行。34 輪使用不同的新建 PG cluster，完成後清理。失敗卡記錄候選修改、測試／交付狀態及工具行動，沒有把 thinking 或 final cause 當成下一輪的推理證據。

## 模型實際查了什麼

| 工具行動 | E4B-only | E4B＋AHE |
| --- | ---: | ---: |
| 讀來源 | 25 | 136 |
| 請求精確原始碼補件 | 5 | 19 |
| 搜尋證據摘要 | 無此工具 | 5 |
| 關係遍歷 | 無此工具 | 0 |
| 查詢回傳未知來源 ID | 2 | 16 |

兩組沒有直接按歷史卡 ID 讀正文，但初始目錄一直可見；AHE 第 5 輪搜尋送達第 1 輪卡片片段，第 24 輪送達歷史索引片段。因此不能從未直接讀卡推論「歷史完全沒有影響」，也不能由入庫紀錄推論「模型已採用」。

AHE 成功輪讀了四次：修補程式前 100 字元、參數說明全文、同一份說明全文、修補程式前 1,500 字元。only 成功輪一次讀完 2,463 字元的修補程式。兩者成功輪都沒有直接讀 `_iter` 函式正文；解釋文字的正確性須另外查證。

兩份成功候選不同：only 把 `_iter` 的 `fitted=True` 改成 `fitted=False`；AHE 改用 `self.transformers_` 取得名稱。兩者皆通過所選 187 項，沒有據此聲稱完整語意等價。

5 次明確不交補丁發生於 1、2、3、11、32 輪。它們是可觀察的克制行為，**尚未按新指標判定為 5 次合理拒答**。9 次構造失敗另列。後續使用 [拒答與收手評估方法](DECISION_RESTRAINT_EVALUATION.md)，分開看該停時停、過度停手、無據說明與真正的修補進展。

## 成功後再跑，與原輸入重播

兩種後續都各組只跑一次，使用新生成的候選並重新評測。

| 後續方式 | E4B-only | E4B＋AHE |
| --- | --- | --- |
| 加入各自成功歷史，接續下一輪 | 第 19 輪：0/3＋179/184；2 次呼叫、1 次工具 | 第 35 輪：舊碼不匹配，未構造補丁、未送測；2 次呼叫、1 次工具 |
| 還原原成功輪的完全相同輸入 | 3/3＋184/184；2 次呼叫、1 次工具 | 3/3＋184/184；5 次呼叫、4 次工具 |

接續輪除了新增成功卡／目錄，也修改 system 對「只有失敗歷史」的描述；初始請求改變欄位為 `system` 與 `prompt`。不能把退步單獨歸因於成功卡的語意，也不能把新增歷史後的一輪失敗說成相同輸入不穩定。

原樣重播則逐次在送出前比對請求序列化 bytes，讓模型自行選擇動作；若動作分岔就停止，而非強迫重演。實際沒有分岔：兩組所有請求、動作、工具對話、回答／thinking 原文字串及補丁都與各自成功輪相同。這是每組一次重播的觀察，不是跨組輸入相同，也不是無限次保證。

AHE 重播重新建立空 PG、實際接納原有 49 份資料並查詢，四角色連線且清理完成；only 無 AHE。兩組新測試 log 均逐項核對 187 個唯一識別碼及狀態。重播成本為 only 輸入 17,739／生成 2,532 tokens，AHE 76,672／5,661 tokens。
