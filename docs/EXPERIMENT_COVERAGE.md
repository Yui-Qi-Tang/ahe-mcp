# 實驗範圍、已知結果與後續事項

整理日期：2026-10-15。這份索引只整理 **AHE MCP Product 實際執行的研究與其後續計畫**，不新增模型回答、資料庫操作、測試或評分。各輪的產品版本、輸入與判準不同，不能加總成一個成功率，也不能把舊測驗當成目前 develop 的重新驗證。

目前最清楚的進度是：SWE 自主修補與成功後對照已結束；34 輪狀態追溯已做事後盤點；17 題舊版已取得原生操作紀錄，但人類交接未評分；接入新版 SAT／治理的 v6 仍是待 review 草稿。

## 17 題舊版實跑與新版規劃

**舊版基準**為 `fa1168a7f063bd1a8224c06cb0ed07b3ee803ea6`、schema 57、角色政策 v8；**新版 v6 的規劃目標**為 `bde9cccee7c02bc4de6cc94df8b8ab4c74be1612`、schema 59、角色政策 v10。後者不是這 102 張舊卡的執行版本。

舊版兩組共同材料與原生邏輯投影為 51/51 對一致，包含受阻時點當時的局部狀態；不是 51 對流程全部完成，也不表示整個 DB 位元組相同。A/B 工具呼叫為 536／669；B 有 87 份外部比較紀錄。語意判斷正確是合成假設，接納使用 TEST APPROVAL STUB；原生寫入、審閱與查回有實際執行。

上表是原生收據核對，**不是六問答對卡數**。15 個故事完成三點的原生流程；第 8、11 題只完成初始點。全部 102 卡與 612 格仍保留，未執行或受阻不刪除分母。

舊輪次漏了實跑前的完整逐格答案鍵；之後補寫的覆核 v1–v3 都是事後材料，另有輸入投影與提示移除修訂。這些版本、原卡與原結果保留，沒有回填凍結時間，也沒有重評。它們不能把原生實跑轉成事前凍結的人類交接實驗。

另外核對的 34 份舊封存 DB，正式 `contradicts` 邊為 0；外部比較中的「衝突」不是正式邊。舊版沒有啟動 solver，因此不能以這輪說目前 Product 的 SAT 或獨立矛盾審閱失敗。

## 後續待做事項與暫放範圍

1. **先固定環境與能力。** 目前 develop 已包含候選搜尋、撤回／來源評估／歷史，以及依據政策與提交 guard（Issue 18 Batch 1–4；migrations 58/59）。這是已合入能力，17 題尚未在該版本驗證。移植後的實驗室驗證另立紀錄，不能沿用 Product 成績。
2. **為下一個執行環境重做逐操作對照。** 依本次另立的移植交接計畫，完成實驗室能力／migration／權限／真實 PG 升級與多 client 驗證，再形成新的案例接線版本。這份 Product 摘要不宣稱移植已開始或已完成。
3. **review 新版計畫與逐格鍵。** 保留 A/B 同判準及時點界線；第 8、11、16 題前置問題不能透過換 seed、偷偷補評估或改 Core 來湊滿通過。能力拒絕、未建立情境、未執行與讀者回答錯誤分開。
4. **準備、校準、凍結後才重跑。** 原 34 個案例／組別 DB 加 2 個 QV-C1 控制，校準另計；不共用舊 DB。正式執行前固定來源、操作、投影、評分及所有版本，缺項如實列出。使用者未核准前不啟動正式重跑或評分。
5. **另驗證人類能否接手與模型是否遵守。** 人類交接、由模型自行做寫入前比較、來源語意擷取、少重試與避免強答是不同問題；目前沒有一個總分可以代替。若新增理由欄位、提示或工具策略，另開實驗版本。

跨批次自動命題對齊、全庫 SAT 集合自動擴張、錯誤 contradicts 的撤銷生命週期、通用外部動作執行協調，均未由這次研究完成或驗證；前兩項依使用者決定暫放。300 題 SWE 全量亦未在本輪啟動。這些不是可以從合成案例收據或單題成功外推出來的能力。

原始收據、DB 封存、逐次入出參、舊鍵與 v6 完整管理者材料留在私有驗證紀錄。公開文件與[摘要 JSON](evaluation/intake-state-comparison-20261013-summary.json)保存範圍、數值、版本與來源 hash，移除本機路徑及連線資料；它們不構成可獨立重跑的完整資料包。
